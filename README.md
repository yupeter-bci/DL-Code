# 深度学习学习记录与代码复习

## 我的学习过程

这个目录用于记录我学习 PyTorch 和深度学习的过程。

**这里的代码，我自己都先动手敲了一遍，只是第一遍敲的时候没有写注释。之后为了方便理解和复习，我又把标准的、带注释的代码贴过来，作为后续对照学习的参考。**

我的学习顺序是：

1. 先自己逐行敲一遍代码，熟悉语法、API 和实现流程。
2. 第一遍主要关注代码实现，没有写注释。
3. 再贴入标准的带注释代码，对照理解每一步的作用。
4. 复习时结合代码、课件和课堂笔记，回顾原理与实现细节。

这里的“标准带注释代码”指学习时用于对照的参考版本，方便我回顾第一遍练习的内容，并补充理解每一步的作用。

## 运行方式

这些文件是独立的学习脚本，没有统一启动入口。所用第三方库包括：

| 库 | 代码中的用途 |
| --- | --- |
| torch | 张量、自动微分、神经网络与训练 |
| torchvision | CIFAR-10 数据集和图像转换 |
| numpy、pandas | 数组操作与表格数据处理 |
| matplotlib | 绘制函数曲线和显示图像 |
| scikit-learn | 模拟回归数据、划分数据集和特征标准化 |
| torchsummary | 查看网络结构与参数 |
| jieba | 中文分词 |

请在自己的 Python 环境中准备这些依赖。当前资料未提供统一的依赖版本锁定文件；本文没有验证特定 Python、PyTorch 或 CUDA 版本组合。

在 PowerShell 中，先进入脚本所属的日期目录再执行。例如，从本 README 所在目录开始：

```powershell
# 基础张量示例
Set-Location './代码/day01'
python './01_张量的基本创建方式.py'

# 切换到 day06，运行手机价格分类优化版
Set-Location '../day06'
python './02_ANN案例_手机价格分类案例_优化版.py'
```

运行前留意：

- 脚本中的 `./data/` 和 `./model/` 相对于终端当前工作目录解析，因此应在对应的 day 目录中运行。在 IDE 中也要设置相应的工作目录。
- 部分脚本定义了多个 `dm01()`、`dm02()` 等演示函数，实际执行哪些示例取决于文件末尾的调用；复习时可按需切换。
- day05、day06 的手机价格案例使用各自 `data/手机价格预测.csv`；day06 的图像演示使用 `data/a.jpg` 和 `data/img.jpg`。
- day06、day07 的 CIFAR-10 脚本设置了 `download=True`，本地数据缺失时会尝试下载。
- day07 的歌词案例读取 `data/jaychou_lyrics.txt`。
- 涉及模型保存时，需确保当前 day 目录下有 `model/` 文件夹。训练会写入代码指定的 `.pth` 文件，同名文件会被覆盖。
- day06 的手机价格优化版默认先训练再评估；day07 的 CNN 和歌词生成案例默认加载已有模型进行评估或生成，训练调用目前被注释。若缺少对应权重，需要先启用训练步骤生成模型。
- 绘图脚本可能弹出图形窗口；部分脚本指定了 `SimHei` 字体，中文显示异常时可检查本机字体设置。

## 我的复习方式

每次复习一个文件时，先回想第一遍自己敲代码时的实现思路，再阅读参考版本中的注释，重点回答：

1. 这段代码要解决什么问题，输入和输出分别是什么？
2. 每一步张量的形状、数据类型有没有变化？
3. 前向传播、损失计算、梯度清零、反向传播和参数更新分别在哪里？
4. 当前参数或 API 为什么这样设置，修改后可能产生什么影响？
5. 不看注释时，能否重新写出核心流程，并用自己的话解释？

遇到不理解的部分，结合 [课件](课件/) 和 [课堂笔记](课堂笔记/) 回顾，再回到对应代码验证理解。
